## О проекте

**HealthBand** — умный браслет для здоровья, который отслеживает физическую активность, качество сна и пульс в режиме 24/7.

**Целевая аудитория:** активные жители городов 25–45 лет, заботящиеся о здоровье, фитнесе и современных технологиях.

**Главная цель лендинга:** познакомить посетителя с продуктом, снять возражения через социальные доказательства и мотивировать к покупке.

**Основное целевое действие (CTA):** нажатие на кнопку «Купить» / «Оформить заказ».

## Возможности

- Полностью адаптивный дизайн (мобильные, планшеты, десктоп)
- Семантичная HTML5-разметка
- Современный CSS3: Grid, Flexbox, CSS-переменные, анимации
- Минималистичный JavaScript (ES6) без зависимостей
- Эффект glassmorphism в шапке сайта
- Плавное появление блоков при прокрутке (fade-in)
- Мобильное бургер-меню
- Слайдер отзывов
- Интерактивная схема браслета с подсказками
- Модальное окно быстрого заказа
- Блок цены с акционной скидкой и таймером обратного отсчёта
- Формы захвата лидов (имя + телефон)

| Параметр | Значение |
|----------|----------|
| Базовая цена | **3 990 ₽** |
| Скидка на старте | **15%** (первая неделя продаж) |

## Быстрый старт

### Локальный запуск

1. Клонируйте репозиторий:

```bash
git clone https://github.com/dimitry8st-prog/-_-_-.git
cd -_-_-
```

2. Откройте `index.html` в браузере:

- Двойной клик по файлу, **или**
- Через Live Server в VS Code / Cursor, **или**
- Локальный сервер:

```bash
# Python 3
python -m http.server 8000

# Node.js (npx)
npx serve .
```

Дополнительная установка зависимостей **не требуется**.

## Интерактивные элементы

### Навигация
- Фиксированная шапка с эффектом размытия (glassmorphism)
- Плавный скролл к якорным секциям
- Бургер-меню на экранах ≤ 768px

### Отзывы
- Слайдер с кнопками «назад» / «вперёд» и точками-индикаторами
- На десктопе — 3 карточки в ряд, на мобильных — по одной

### Схема браслета
- Точки-датчики с всплывающими подсказками при наведении и фокусе

### Формы заказа
- Валидация полей «Имя» и «Телефон»
- Сообщение об успешной отправке (демо-режим, без бэкенда)
- Модальное окно открывается по всем CTA-кнопкам «Купить»

### Таймер акции
- Обратный отсчёт 7 дней с первого визита
- Данные хранятся в `localStorage` (ключ: `healthband_promo_end`)

## Деплой

Проект — статический сайт. Можно разместить на любом хостинге:

- **GitHub Pages** — включите Pages в настройках репозитория, источник: ветка `main`
- **Netlify** — перетащите папку на [netlify.com](https://www.netlify.com)
- **Vercel** — импортируйте репозиторий на [vercel.com](https://vercel.com)
- Любой shared-хостинг — загрузите файлы через FTP
